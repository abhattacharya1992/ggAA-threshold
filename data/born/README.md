# Tree-level amplitudes

`original/` holds the tree-level projections from the 2019 calculation, unchanged:

| file | contents |
|---|---|
| `ggAA01` | Type II, projector 1, in d = 4 + eps (`eps` terms are O(eps)) |
| `ggAA02` | Type II, projector 2, in d = 4 + eps |
| `ggAA_A_01` | Type I, projector 1: i s/3 |
| `ggAA_A_02` | Type I, projector 2: 0 |
| `BornSqr.log` | FORM output: polarization-summed Type-II Born squared in n dimensions, times CG^4 and a colour factor |

An earlier version of `ggAA01` carried an extra colour sum (N^2 - 1) that `ggAA02` does not;
the version here is the corrected one. With it, (|M_1|^2 + |M_2|^2)/BornSqr(n = 4) is constant
(= 1/4) over phase space.

The four-dimensional Type-II Born used by the code (`src/python/ggaa/born.py`) is

    M_1^(0) = i s / 2,   M_2^(0) = i m_A^2 (x - z)(x^2 + 1)(x z - 1) / (4 x z (x^2 - x z + 1)),

with C_G^2 and delta^{ab} stripped. It is checked in `scripts/check_normalization.py` against
`BornSqr.log`, against a direct evaluation of the two Feynman diagrams, and against the
imaginary part of the one-loop remainder generated by the infrared subtraction.
