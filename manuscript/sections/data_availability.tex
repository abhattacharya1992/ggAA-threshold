\section*{Data Availability}
\label{sec:dataavailability}

The threshold series, construction files, construction and validation code,
outputs of the original runs, validation records, code for numerical evaluation, endpoint constant reductions, tree-level projections, the one-loop $gg\to HH$ coefficients used in Sec.~\ref{sec:dps} and the scripts that reproduce all tables and figures form a self-contained package.
The updated version is provided as ancillary files with the arXiv version of this article and as Supplemental Material~\cite{SupplementalMaterial}.
It is maintained at \url{https://github.com/abhattacharya1992/ggAA-threshold}.
The unexpanded finite remainders of Ref.~\cite{Bhattacharya:2019bmd} are downloaded from arXiv by the package and checked against their checksums.
The code used to generate the one-loop $gg\to HH$ coefficients is not included and is available from the author on request.
