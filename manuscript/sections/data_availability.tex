\section*{Data Availability}

The threshold series, construction files, validation records, the code of the construction and validation, the evaluator, the one-loop $gg\to HH$ coefficients of Sec.~\ref{sec:dps} and the scripts that reproduce all tables and figures form a self-contained package. Version~7.2.1 is provided as ancillary files with the arXiv version of this article and as Supplemental Material~\cite{SupplementalMaterial}; the package is maintained at \url{https://github.com/abhattacharya1992/ggAA-threshold}. The unexpanded finite remainders used as input were released as ancillary files with Ref.~\cite{Bhattacharya:2019bmd}; the package downloads them from arXiv and verifies their checksums. The code used for the one-loop $gg\to HH$ amplitudes of Sec.~\ref{sec:dps} is not included; it is available from the author on request.
