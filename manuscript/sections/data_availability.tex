\section*{Data Availability}
\label{sec:dataavailability}

The threshold series, construction files, construction and validation code,
outputs of the original runs, validation records, code for numerical evaluation, endpoint constant reductions, tree-level projections, the one-loop $gg\to HH$ coefficients used in Sec.~\ref{sec:dps} and the scripts that reproduce all tables and figures form one package, in which the one-loop $gg\to HH$ coefficients enter as computed values.
The updated version is provided as ancillary files with the arXiv version of this article and as Supplemental Material~\cite{SupplementalMaterial}.
It is maintained at \url{https://github.com/abhattacharya1992/ggAA-threshold} and archived at Zenodo, \href{https://doi.org/10.5281/zenodo.23597489}{doi:10.5281/zenodo.23597489}.
The unexpanded finite remainders of Ref.~\cite{Bhattacharya:2019bmd} are downloaded from arXiv by the package and checked against their checksums.
The released script \texttt{scripts/check\_dps\_hh.py}
compares the supplied forward coefficients with $F_A$ and
$F_S$ and checks their ratio in units of the respective tree
amplitudes.
The reproduction of the earlier $gg\to AA$ result and the
double-pole checks are read from the supplied run log, not
recomputed by this script.
The code used to generate the one-loop $gg\to HH$ coefficients is not included and is available from the author on request.
