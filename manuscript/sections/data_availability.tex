\section*{Data Availability}

The threshold series, construction files, validation records, evaluator, the one-loop $gg\to HH$ coefficients of Sec.~\ref{sec:dps} and the scripts that reproduce all tables and figures are provided as ancillary files with the arXiv version of this article and as Supplemental Material~\cite{SupplementalMaterial}. The unexpanded finite remainders used as input were published with Ref.~\cite{Bhattacharya:2019bmd}. The code used for the one-loop $gg\to HH$ amplitudes of Sec.~\ref{sec:dps} is not included; it is available from the author on request.
